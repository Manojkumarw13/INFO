## NotebookLM Source Compatibility Rules Applied

| Source Type | Compatible? | How to Add |
|---|---|---|
| Public web page (docs, courses, blogs) | ✅ YES | Paste URL directly |
| YouTube individual video | ✅ YES | Paste YouTube URL (requires captions) |
| Direct PDF link (arxiv, university servers) | ✅ YES (download → upload) | Download file, upload to notebook |
| Google Docs / Slides | ✅ YES | Paste Google URL |
| .txt / .md / .docx / .csv / .pptx files | ✅ YES (upload) | Download, upload to notebook |
| GitHub repositories | ❌ NO | Excluded — repo structure not ingestible |
| Interactive platforms (LeetCode, SQLZoo, Visualgo, Brainstellar) | ❌ NO | Excluded — dynamic JS content |
| Paywalled pages (O'Reilly, Coursera full content) | ❌ NO | Excluded — paywall blocks scraping |
| Login-required platforms (Redis University) | ❌ NO | Excluded — auth wall |
| Search result pages | ❌ NO | Excluded — not a resource |
| 3D / interactive visualizations (LLM Viz, Spline) | ❌ NO | Excluded — no text content |
| YouTube playlists | ⚠️ ADD INDIVIDUALLY | Add each video URL separately |

> **Note:** For YouTube playlists, NotebookLM ingests the transcript of each video. Add individual video URLs. For MIT OCW courses, both the course page URL and individual lecture PDF downloads work. Limit is 50 sources per notebook (free) / 300 sources (Plus).
