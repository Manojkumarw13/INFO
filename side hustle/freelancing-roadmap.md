## 2. Services to Offer (Tiered)

Structure your services in three tiers. **Start with Tier 1 only** for your first 30 days — resist the urge to offer everything.

---

### 🟢 Tier 1 — Entry Services (Days 1–30)
*Low complexity. Fast to deliver. Perfect for getting first clients and reviews.*

#### 2.1 Excel/Google Sheets Automation
- Clean messy datasets, build automated trackers, create formulas dashboards
- **Deliverable:** `.xlsx` file with documentation
- **Time to deliver:** 2–5 hrs per project
- **Who buys:** Small businesses, accountants, HR teams, founders

#### 2.2 Power BI Dashboard (Basic)
- Connect to Excel/CSV data, build 3–5 page report with KPIs and charts
- **Deliverable:** `.pbix` file + PDF screenshot export
- **Time to deliver:** 4–8 hrs
- **Who buys:** Startups, sales teams, operations managers

#### 2.3 Notion Workspace Setup
- Build team wikis, project management systems, client portals in Notion
- **Deliverable:** Shared Notion workspace + Loom walkthrough video
- **Time to deliver:** 3–6 hrs
- **Who buys:** Solopreneurs, coaches, small teams, agencies

#### 2.4 Data Cleaning & Analysis (Python/SQL)
- Clean raw data, run descriptive analysis, deliver insights report
- **Deliverable:** Cleaned `.csv` + Python notebook or SQL scripts + PDF summary
- **Time to deliver:** 3–8 hrs
- **Who buys:** Researchers, e-commerce brands, logistics companies

---

### 🟡 Tier 2 — Core Services (Days 30–60)
*Moderate complexity. Higher value. Requires portfolio proof before selling.*

#### 2.5 AI Chatbot / Assistant (Claude/Gemini API)
- Build custom chatbots for FAQs, lead capture, internal knowledge bases
- **Deliverable:** Working web embed or API + documentation
- **Time to deliver:** 8–15 hrs
- **Who buys:** EdTech, HR teams, SaaS startups, e-commerce

#### 2.6 Power BI Advanced Dashboard + Reporting System
- Full BI solution: data model, DAX measures, automated refresh, role-level security
- **Deliverable:** `.pbix` + Power Automate flow + user guide
- **Time to deliver:** 10–20 hrs
- **Who buys:** Mid-size companies, finance teams, marketing agencies

#### 2.7 AI-Powered Automation (n8n / Make / Python)
- Automate repetitive workflows: data pipelines, report generation, email summaries using AI
- **Deliverable:** Working automation + documentation
- **Time to deliver:** 6–12 hrs
- **Who buys:** Agencies, SaaS companies, operations-heavy SMEs

#### 2.8 Custom Canva + Data Presentation Design
- Transform raw data into executive-ready presentations and infographics
- **Deliverable:** Editable Canva/PowerPoint file
- **Time to deliver:** 4–8 hrs
- **Who buys:** Consultants, founders, NGOs, marketing teams

---

### 🔴 Tier 3 — Premium Services (Days 60–90+)
*High complexity. Retainer-worthy. Position as ongoing partnerships.*

#### 2.9 End-to-End Data Pipeline + Dashboard
- SQL → Python ETL → Power BI dashboard → automated reporting cadence
- **Deliverable:** Full working system + maintenance SOP
- **Time to deliver:** 20–40 hrs
- **Who buys:** Growing startups, D2C brands, logistics firms

#### 2.10 AI Application Development
- Build AI-powered internal tools: document analyzers, data extractors, smart search systems
- **Deliverable:** Deployed web app (Streamlit/HTML) + source code
- **Time to deliver:** 15–30 hrs
- **Who buys:** Professional services firms, EdTech, HR tech

#### 2.11 Fractional Data Analyst (Monthly Retainer)
- Ongoing analysis, dashboards, reporting, and ad-hoc queries
- **Deliverable:** Weekly/monthly reports + Slack/email support
- **Who buys:** Startups without a full-time analyst

## 3. Pricing Strategy

### Starting Prices (Month 1 — Build Reviews)

| Service | Introductory Price | Market Rate (after 3 reviews) |
|---|---|---|
| Excel Automation | ₹1,500–₹3,000 | ₹4,000–₹8,000 |
| Notion Workspace | ₹2,000–₹4,000 | ₹5,000–₹12,000 |
| Basic Power BI Dashboard | ₹3,000–₹5,000 | ₹8,000–₹18,000 |
| Data Cleaning + Analysis | ₹2,000–₹4,000 | ₹5,000–₹12,000 |
| AI Chatbot (basic) | ₹5,000–₹8,000 | ₹12,000–₹30,000 |
| Advanced Dashboard | ₹8,000–₹12,000 | ₹20,000–₹40,000 |
| Monthly Retainer | ₹8,000–₹12,000/mo | ₹20,000–₹50,000/mo |

### Pricing Rules

1. **Never charge by the hour publicly.** Always quote project-based pricing. It rewards speed and skill.
2. **Use anchoring.** Always present 3 packages (Basic / Standard / Premium). Most clients pick the middle.
3. **Raise rates by 20–30% after every 3 positive reviews.** Do not negotiate down — offer to reduce scope instead.
4. **₹20K/month math at Tier 1:**
   - 2 Power BI dashboards (₹4,000 each) = ₹8,000
   - 3 Notion workspaces (₹3,000 each) = ₹9,000
   - 2 data cleaning projects (₹2,500 each) = ₹5,000
   - **Total: ₹22,000** — achievable in 1–2 hrs/day with 7 projects/month

## 4. Portfolio Projects to Build

Build these **before** applying to any client. No real client needed — these are mock projects that demonstrate real skill. Host everything publicly (GitHub + LinkedIn + Notion page).

> ⏱ Time budget: 3–5 hrs total across Days 1–14

---

### Portfolio Project 1 — Sales Performance Dashboard (Power BI)
**Story:** "I built a Power BI dashboard for a fictional D2C brand to track monthly revenue, top SKUs, and regional performance."

- Dataset: Download free Kaggle dataset (Superstore Sales or similar)
- Build: 4-page Power BI report with slicers, KPI cards, trend lines, map visual
- Export: PDF screenshots + publish to Power BI Service (free)
- Host: LinkedIn post with screenshots + GitHub repo with `.pbix`

---

### Portfolio Project 2 — Python Data Analysis Report
**Story:** "Analyzed 12 months of e-commerce transactions to identify churn patterns and revenue opportunities."

- Dataset: Free dataset from Kaggle (e-commerce orders)
- Build: Jupyter Notebook with pandas, matplotlib/seaborn — EDA + insights summary
- Export: PDF report generated from notebook (nbconvert)
- Host: GitHub repo + LinkedIn carousel post

---

### Portfolio Project 3 — AI Customer Support Chatbot
**Story:** "Built an AI-powered FAQ bot for a coaching business using Claude API — handles 80% of repetitive questions."

- Build: Python + Claude API (or Streamlit UI) with a custom system prompt
- Use case: Coaching FAQ / e-commerce returns / HR policy bot
- Host: Deploy on Streamlit Community Cloud (free) — shareable live link
- Show: Demo video (Loom, 2 minutes) + GitHub repo

---

### Portfolio Project 4 — Notion Client Portal Template
**Story:** "Designed a complete client onboarding and project management system for freelance consultants in Notion."

- Build: Notion workspace with: Client database, project tracker, invoice log, onboarding checklist
- Host: Duplicate-able public Notion link + Canva cover image
- Bonus: List it free on Gumroad or Notion.so templates gallery

---

### Portfolio Project 5 — Excel Automation Dashboard
**Story:** "Automated a manual HR attendance tracker, reducing monthly reporting time from 4 hours to 15 minutes."

- Build: Excel file with VLOOKUP/INDEX-MATCH, pivot tables, dynamic charts, a simple macro
- Host: GitHub + LinkedIn screenshot post

---

### Portfolio Presentation Tips

- Write a 3-line case study for each: **Problem → What you built → Result (quantify if possible)**
- Create a simple Notion page as your "portfolio hub" linking all 5 projects
- Record a 90-second Loom video walking through your best project — embed it everywhere

## 5. Client Acquisition Platforms

### Phase 1: Indian Platforms First (Days 1–45)

Start here. Lower competition, INR payments, clients expect student/fresher profiles.

| Platform | Best For | Action |
|---|---|---|
| **Internshala** | Data, design, dev projects | Apply to 5 projects/day. Mention your portfolio link in every proposal. |
| **Truelancer** | All Tier 1 services | Set up profile Day 1. Bid on 3–5 projects daily. |
| **WorkIndia** | Data entry, analysis, VA work | Good for quick first projects while building reviews elsewhere. |
| **LinkedIn** | Direct B2B clients, retainers | Most powerful long-term channel. Post daily. DM founders. |
| **Local Facebook Groups** | SME owners, coaches | Search "Business owners [your city]" — offer free audits to start conversations. |

### Phase 2: Global Platforms (Days 30–90)

Add these once you have 2–3 reviews from Phase 1.

| Platform | Best For | Action |
|---|---|---|
| **Fiverr** | Power BI, AI chatbots, Notion templates | Create 2 gigs. Optimize title/tags for search. Respond within 30 min. |
| **Upwork** | Retainers, larger data projects | Write personalized proposals. Apply to jobs with <10 proposals. |
| **Contra** | Commission-free, modern clients | Great for AI/tech services. 0% fee — more take-home than Fiverr/Upwork. |

### Phase 3: Direct Outreach (Days 45+)

This is where the best clients come from — no platform fees, no competition.

**LinkedIn DM Template (personalized):**
```
Hi [Name],

I noticed [specific observation about their business/LinkedIn post].

I help [type of business] [specific outcome — e.g., "get clear on their data 
with Power BI dashboards so they can make faster decisions"].

I've recently built [portfolio example]. Would it be useful if I did a quick 
free audit of your current [reporting/data/workflow]?

No pitch — just a 15-min call if there's a fit.
```

**Who to DM:**
- Startup founders with 5–50 employees (LinkedIn filter)
- Digital marketing agency owners
- EdTech and coaching business owners
- E-commerce brand owners (Instagram → LinkedIn)

## 6. Content Strategy

> **Goal:** Become the person people think of when they need data/AI help. Posting = inbound leads.

### Platform Priority

1. **LinkedIn** — Primary. Business buyers live here. Post 4–5x/week.
2. **Twitter/X** — Secondary. Tech/AI community. Post 2–3x/week (repurpose LinkedIn).
3. **Instagram** — Optional. Canva carousels, dashboard screenshots. 2x/week.

---

### LinkedIn Content Pillars (Rotate Weekly)

| Pillar | What to Post | Example |
|---|---|---|
| **Show Your Work** | Behind-the-scenes of a project | "Here's a Power BI dashboard I built for a mock D2C brand. 5 KPIs, 4 pages, 0 manual refresh. Thread 🧵" |
| **Teach Something** | 1 tip or trick from your skillset | "Most analysts waste 2 hours/week doing this in Excel. Here's how to fix it in 5 minutes." |
| **AI in the Wild** | Real use case of Claude/Gemini at work | "I used Claude API to build a chatbot that answers 80% of FAQ questions for a coaching business. Here's how." |
| **Results & Case Studies** | Before/after from your portfolio | "Manual report: 3 hours. Automated with Python + Power BI: 8 minutes. Here's what I built." |
| **Personal POV** | Opinion on trends in data/AI | "Everyone's building AI chatbots. Almost nobody is connecting them to real business data. That's the gap." |

---

### Weekly Content Schedule (1–2 hrs/week total)

| Day | Platform | Content Type | Time |
|---|---|---|---|
| Monday | LinkedIn | Teach something (tip/trick) | 20 min |
| Wednesday | LinkedIn | Show your work (portfolio WIP or project) | 20 min |
| Friday | LinkedIn | Results / case study / opinion | 20 min |
| Saturday | Instagram | Carousel repurposed from best LinkedIn post | 15 min |

> Use **Claude** to draft posts. Prompt: *"Write a LinkedIn post about [topic]. Tone: professional but conversational. No fluff. Include a hook, 3 key points, and a call to action. Under 200 words."* Then edit in your own voice.

### Content Growth Hack

Comment meaningfully on 5 posts per day from your target clients (founders, SME owners, marketing heads). A thoughtful comment gets more profile views than a standalone post.

## 8. Recurring Income & Scaling to a Business

### Step 1: Convert Projects to Retainers

After delivering a project well, always propose a retainer:

> *"I can maintain and update this dashboard monthly, add new data sources as your business grows, and be on-call for ad-hoc analysis — all for ₹[X]/month. Interested?"*

**Retainer tiers to offer:**
- **Basic** — ₹8,000–₹12,000/mo: Monthly report + 2 revision rounds
- **Standard** — ₹15,000–₹25,000/mo: Weekly updates + Slack support + quarterly deep-dives
- **Premium** — ₹30,000–₹50,000/mo: Fractional data analyst — unlimited queries, priority support

**3 retainer clients at ₹15,000 = ₹45,000/month passive-ish base.**

---

### Step 2: Productize Your Services

Turn your most-requested service into a fixed, repeatable product:

| Productized Service | What It Is | Price |
|---|---|---|
| "Starter Dashboard in 48 Hours" | Standard Power BI template + your data | ₹7,999 flat |
| "AI Bot in a Week" | Claude/Gemini FAQ chatbot, deployed | ₹14,999 flat |
| "Notion HQ Setup" | 5-database team workspace, templated | ₹4,999 flat |
| "Data Health Check" | Audit + report on business data quality | ₹2,999 flat |

Productized services remove scope creep, are faster to deliver, and easier to sell.

---

### Step 3: Passive Income Streams

Build once, sell repeatedly:

- **Notion Templates** on Gumroad / Notion Template Gallery — ₹299–₹999 per sale
- **Power BI Dashboard Templates** on Gumroad or Etsy — ₹499–₹1,999 per sale
- **Python/Excel Automation Scripts** on GitHub (paid) or Gumroad
- **Mini-courses** on Teachable or Gumroad: "Build a Power BI Dashboard in 2 Hours" — ₹999–₹2,999

Start with Notion templates (lowest effort, fastest to publish).

---

### Step 4: Scale to an Agency / Studio

Once you're consistently at ₹50K+/month:

1. **Hire 1 sub-contractor** (student/fresher) for Tier 1 work at ₹8,000–₹15,000/month. You keep the margin.
2. **Specialize your positioning:** Become "the Power BI + AI person for D2C brands" or "the Notion systems person for coaches." Niching multiplies rates.
3. **Build a simple website** (HTML + your skills) with a clear headline, services, portfolio, and contact form.
4. **Register as a freelancer** with a GST number once annual income crosses ₹20 lakh. Use a current account for professional invoicing.
5. **Offer white-label services** to agencies — they resell your dashboards/AI work to their clients at a markup. Steady volume, no client acquisition.
